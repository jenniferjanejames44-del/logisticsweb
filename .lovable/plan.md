# Quotation Management System (Admin Dashboard)

A net-new feature. RAC Logistics currently has no `quotations` table, no admin quotations page, no PDF/WhatsApp share for quotes. Everything below is additive — shipments, invoices, payments, pricing engine, and user dashboard are not touched.

## 1. Database (new migration, additive only)

### `quotations` table
- `id uuid pk`, `quote_number text unique` (e.g. `QT-2026-00001`, generated by trigger)
- `user_id uuid` (nullable — quotes can be drafted for non-registered customers)
- `customer_name text`, `customer_email text`, `customer_phone text` (E.164)
- `shipment_type text` — `import` | `export`
- `origin_country`, `origin_city`, `destination_country`, `destination_city`
- `warehouse_country` (nullable, import only)
- `shipping_method text` — `air` | `sea` | `road`
- `service_type text` (nullable)
- `weight_kg numeric`, `length_cm`, `width_cm`, `height_cm`, `chargeable_weight numeric`
- `description text`, `declared_value numeric`
- `pricing_rule_id uuid` (nullable, refs `pricing_rules`)
- `currency text` default `'USD'`
- `subtotal`, `handling_fee`, `customs_fee`, `vat`, `insurance`, `total numeric`
- `pricing_snapshot jsonb` — full breakdown returned by `computeShipmentTotalsV2`
- `ngn_total numeric` (nullable — computed via `exchange_rates` when sent)
- `status text` default `'draft'` — `draft|sent|accepted|rejected|expired|converted`
- `valid_until date` (default `now() + 7 days`)
- `pdf_url text` (nullable, populated by generator)
- `sent_at`, `accepted_at`, `rejected_at`, `converted_at` timestamps
- `converted_shipment_id uuid` (nullable), `converted_invoice_id uuid` (nullable)
- `notes text`, `created_by uuid`, `created_at`, `updated_at`

RLS:
- `Admins can manage quotations` — ALL using `has_role(auth.uid(),'admin')`
- `Users can view their own quotations` — SELECT where `auth.uid() = user_id`

Trigger: `generate_quote_number()` → `QT-YYYY-NNNNN` sequence (sequence on year + counter); `update_updated_at_column` trigger.

## 2. Pricing reuse
- Quote creation form reuses `matchPricingRule()` + `computeShipmentTotalsV2()` from `src/lib/pricingEngineV2.ts`. Stores full breakdown in `pricing_snapshot` so the quote remains stable even if rules change later.
- No changes to pricing engine.

## 3. PDF generation
- New edge function `generate-quotation-pdf` (mirrors existing `generate-invoice-pdf` pattern). HTML→PDF, uploads to existing `invoices` storage bucket under `quotations/<id>.pdf`, writes `pdf_url` back.
- Layout: RAC Logistics header, quote number, dates, customer block, shipment block, pricing breakdown table, totals (in rule currency + NGN equivalent), validity notice, signature line.
- `verify_jwt = true` (default).

## 4. Admin UI

### Route `/admin/quotations` (list)
- Sidebar entry "Quotations" with `FileText` icon, between Invoices and Payments.
- Header: title + "Create Quotation" primary CTA.
- Filters: status select, search by quote/customer, date range.
- Desktop: `Table` with columns Quote #, Customer, Type, Origin → Destination, Total, Currency, Status badge, Created, Actions.
- Mobile: stacked Card list (same data, action menu).
- Row actions (compact icon buttons + overflow `DropdownMenu`): View, Edit, Download PDF, Send WhatsApp, Send Email, Convert to Shipment, Convert to Invoice, Delete.

### Route `/admin/quotations/:id` (detail)
- 3-column summary cards (Customer · Shipment · Totals).
- Pricing breakdown table.
- Status timeline (created → sent → accepted/converted).
- Action bar: Download PDF · Print · Send WhatsApp · Send Email · Convert to Shipment · Convert to Invoice · Edit · Delete.

### Modals (all using `ModalShell` — sticky header, scroll body, sticky footer)
- **Create/Edit Quote** — multi-section form: Customer, Shipment, Package, auto-calculated Pricing preview, Notes & validity.
- **WhatsApp Preview** — phone input prefilled, editable textarea prefilled with the template message, copy button, "Open WhatsApp" primary button → builds `https://wa.me/<digits>?text=<encoded>` and opens new tab; marks quote `sent` and stamps `sent_at`.
- **Send Email** — subject/body editable, calls existing `send-notification-email` function with the quote PDF link.
- **PDF Preview** — iframe `srcDoc` (matches existing invoice preview pattern).
- **Delete Confirm** — standard `DeleteConfirmDialog`.

## 5. WhatsApp message template
```
Hello {customer_name},

Your RAC Logistics quotation is ready.

Quote No: {quote_number}
Shipment: {origin_country} → {destination_country}
Total: {currency} {total}{ngn_line}
Valid Until: {valid_until}

View your quotation: {pdf_url}

Thank you,
RAC Logistics
```
- `ngn_line` appears when currency ≠ NGN: `\n≈ ₦{ngn_total} (Paystack)`.
- Phone normalized to digits only for `wa.me` link.

## 6. Conversion flows
- **Convert to Shipment**: opens confirm modal → inserts a new `shipments` row using the quote's data (`origin_*`, `destination_*`, `weight`, `chargeable_weight`, dims, `price`, `items_json.pricing = pricing_snapshot`, `payment_status='unpaid'`). Updates quote: `status='converted'`, `converted_shipment_id`, `converted_at`. Existing `auto_create_invoice` trigger handles invoice creation.
- **Convert to Invoice (standalone)**: inserts an `invoices` row directly with the breakdown and links it; only available when not already converted to a shipment.
- Both reuse the user's existing logic — no edits to shipment/invoice creation code paths beyond inserting rows.

## 7. Design system (per memory)

## 9. Safety
- All SQL additive. No edits to existing tables.
- New edge function only; existing functions unchanged.
- Conversion flows only `INSERT` into existing tables using current columns — no schema or trigger modifications.
- Feature is gated by `has_role(admin)`; customer views are read-only.
